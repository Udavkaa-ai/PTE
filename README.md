# ПТЭ Тест — Android-приложение

Приложение для подготовки к аттестации по **Правилам технической эксплуатации
железных дорог Российской Федерации** (ПТЭ, приказ Минтранса России № 250
от 23.06.2022, с приложениями ИСИ и ИДП).

## Возможности

- **Режим теста** — 300 вопросов из аттестационного списка. После выбора
  варианта приложение показывает, правильно ли отвечено, подсвечивает верный
  ответ и выводит **ссылку на соответствующий пункт ПТЭ/ИСИ/ИДП**. Вопросы
  перемешиваются, ведётся счёт правильных ответов.
- **Поиск ответа** — введите текст вопроса или ключевые слова и сразу получите
  правильный ответ с указанием пункта норматива.
- Вопросы с иллюстрациями (сигналы, схемы перегонов/станций) показывают
  соответствующую картинку.

## Структура проекта

```
app/src/main/
  assets/questions.json     — база из 300 вопросов с ответами и ссылками
  assets/images/            — иллюстрации к вопросам (image1..3.b64, base64)
  java/ru/pte/test/
    Data.kt                 — модель и загрузка вопросов
    MainActivity.kt         — UI на Jetpack Compose (тест + поиск)
```

Формат записи вопроса в `questions.json`:

```json
{
  "id": 1,
  "question": "Текст вопроса",
  "options": ["вариант 1", "вариант 2", "вариант 3"],
  "correct": 1,                       // индекс правильного варианта (с 0)
  "reference": "ПТЭ, разд. I, п. 1",  // ссылка на пункт норматива
  "confidence": "high",               // оценка надёжности ответа (high/med)
  "image": null                       // имя картинки из assets/images или null
}
```

## Сборка APK

### Через GitHub Actions (без локальной установки)
В репозитории настроен workflow `.github/workflows/android.yml`. APK собирается
автоматически при каждом push, а также вручную (вкладка **Actions →
Build APK → Run workflow**). Готовый файл `app-debug.apk` доступен в
**Artifacts** завершившегося запуска.

### Локально (Android Studio / CLI)
```bash
# один раз сгенерировать Gradle wrapper (бинарный gradle-wrapper.jar не хранится в репо):
gradle wrapper --gradle-version 8.7
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```
Требуется JDK 17, Gradle 8.7+ и Android SDK (compileSdk 34). Минимальная версия
Android — 7.0 (API 24). Android Studio сгенерирует wrapper автоматически при
открытии проекта.

## Важно о правильных ответах

База из 300 вопросов содержит много повторов — фактически **102 уникальных
вопроса**. Правильные ответы и ссылки на пункты определены по действующей
редакции ПТЭ (приказ № 250) и подтверждены проверкой источников: 258 вопросов
отмечены как `high`, 42 — как `med` (формулировки общих положений, где номер
пункта приведён ориентировочно по разделу/приложению).

Ответы предназначены для **самоподготовки**. Перед аттестацией сверяйтесь с
официальным текстом ПТЭ, ИСИ и ИДП. Любой ответ легко поправить в
`app/src/main/assets/questions.json`.
